\chapter{Overview and Executive Summary}\label{intro}

As noted in the article \href{https://ieeexplore.ieee.org/document/10420981}{Handwritten Character Recognition: A Comprehensive Survey}, Handwritten Character Recognition (HCR) plays a vital role in numerous domains, including document digitization, automatic text recognition, signature verification, and postal automation. Over the years, HCR has advanced significantly, driven by the growing demand for accurate, efficient recognition systems \autocite{AAASM_SICI10420981}.

\section{Project Description}\label{project-description}

\begin{noteblock}
All the source files for \emph{this Project} are available in the \emph{Project}'s \href{https://github.com/AzKurban-edX-DS/edx.capstone.choose-your-own}{GitHub repository}\autocite{edx.Capstone_CYO}.

\end{noteblock}

In this project, we will develop and explore several HCR models, based on popular ML algorithms that convert handwritten alphanumeric symbols into a digital, machine-readable form.

We will start with \href{https://soulpageit.com/ai-glossary/shallow-learning-explained/}{Shallow Learning (SL)} models, using \href{https://rafalab.dfci.harvard.edu/dsbook-part-2/ml/resampling-methods.html\#sec-knn-cv-intro}{k-Nearest Neighbors (kNN)} and \href{https://rafalab.dfci.harvard.edu/dsbook-part-2/ml/algorithms.html\#sec-random-forests}{Random Forest (RF)} methods. These models development and evaluation are described in detail below in Sections \hyperref[k-nearest-neighbors-principal-component-analysis-knnpca-multiclass-classifier-mcc-model]{k-Nearest Neighbors + Principal Component Analysis (kNN+PCA) Multiclass Classifier (MCC) Model} and \hyperref[random-forest-rf-mcc-model]{Random Forest (RF) MCC Model} of \emph{this Report}, respectively.

Next, we will try \href{https://soulpageit.com/ai-glossary/deep-learning-explained/}{Deep Learning (DL)} models, including \href{https://smltar.com/dldnn}{Dense Neural Network (DNN)} and, finally, \href{https://smltar.com/dlcnn\#what-are-cnns}{Convolutional Neural Network (CNN)} models, as recent research shows that DL performs better at image recognition --- the task addressed by \emph{this Project}.

A more detailed explanation of \emph{Deep Learning} versus \emph{Shallow Learning} can be found in the chapter \href{https://link.springer.com/chapter/10.1007/978-3-031-69499-8_1?status=info&saved-doi=10.1007\%2F978-3-031-69499-8_1}{Machine Learning Methods from Shallow Learning to Deep Learning} of the book \href{https://link.springer.com/book/10.1007/978-3-031-69499-8?status=info&saved-doi=10.1007\%2F978-3-031-69499-8}{Shallow Learning vs.~Deep Learning: A Practical Guide for Machine Learning Solutions} by editors Ömer Faruk Ertuğrul, Josep M. Guerrero, and Musa Yilmaz\autocite{Akinci2024}.

The \textbf{\emph{DNN-Based}} models are as follows:

\begin{itemize}
\tightlist
\item
  \textbf{\emph{DNN-Based Basic MCC Model:}} described in Section \hyperref[dense-neural-network-based-basic-multiclass-classifier-dnnb-mcc-model]{Dense Neural Network-Based Basic Multiclass Classifier (DNNB MCC) Model};
\item
  \textbf{\emph{Tuned DNN-Based MCC Model:}} described in Section \hyperref[tuned-dnn-based-tdnn-mcc-model]{Tuned DNN-Based (TDNN) MCC Model}.
\end{itemize}

The last models we will build and explore, the \textbf{\emph{CNN-Based}} models, are as follows:

\begin{itemize}
\tightlist
\item
  \textbf{\emph{CNN-Based Basic MCC Model:}} described in Section \hyperref[convolutional-neural-network-based-basic-cnnb-mcc-model]{Convolutional Neural Network-Based Basic (CNNB) MCC Model};
\item
  \textbf{\emph{Tuned CNN-Based MCC Model:}} described in Section \hyperref[tuned-cnn-based-tcnn-mcc-model]{Tuned CNN-Based (TCNN) MCC Model}.
\end{itemize}

Finally, we will conduct a final test of the best model we have developed, using a specially designated dataset, and see what we will achieve.

\section{Running the Project}\label{running-the-project}

Once the system environment is fully configured, if you have enough time to execute all the scripts and automatically generate \emph{this report} upon their completion in a single session, the easiest approach is to run the \href{https://github.com/AzKurban-edX-DS/edx.capstone.choose-your-own/blob/main/r/support-scripts/__run-all.R}{\_\_run-all.R} script.

This script serves as a starting point for running the project execution pipeline that culminates in a \emph{PDF report}. It coordinates the process by sequentially executing two main R scripts, ensuring the script files exist, and outputs detailed execution logs to both the console and log files.

The first script it launches, \href{https://github.com/AzKurban-edX-DS/edx.capstone.choose-your-own/blob/main/r/index.R}{index.R}, is the entry point to the project's execution pipeline and the main script that runs all the other execution scripts sequentially.

\subsection{\texorpdfstring{The Main \texttt{R} Script}{The Main R Script}}\label{the-main-r-script}

The \href{https://github.com/AzKurban-edX-DS/edx.capstone.choose-your-own/blob/main/r/index.R}{index.R} script serves as the main orchestrator and \emph{entry point} for \emph{this Project}, focused on \href{https://en.wikipedia.org/wiki/Multiclass_classification}{Multi-Class Classification (MCC)} models applied to the \href{https://www.kaggle.com/datasets/vaibhao/handwritten-characters}{Kaggle Handwritten Character Image Dataset} (which uses \href{https://www.tensorflow.org/datasets/catalog/emnist}{EMNIST data} for Alphabets and Digits).

  Used \emph{EMNIST} data for Alphabets and Digits.
\item
  Transformed the Data using some image processing techniques and convert it to 32,32 pixel black and white images.
\item
  Created the Data set for special character ( @, \#, \$, \& )
\item
  Merged the Categories to avoid the misclassification
\item
  Total 39 Categories in Train and Validation set
\end{enumerate}

  (\href{https://github.com/AzKurban-edX-DS/edx.capstone.choose-your-own/blob/main/r/support-functions/data-helper.R\#L289}{Line 289}) \textbf{\emph{Matrix Conversion \& Validation:}} Converts the loaded image into a numeric matrix representation using the user-defined helper function \hyperref[func.magick_img2matrix]{magick\_img2matrix} described below in described below in the \hyperref[appndx_aux40img_proc]{Image Processing} section.
\item
  (\href{https://github.com/AzKurban-edX-DS/edx.capstone.choose-your-own/blob/main/r/support-functions/data-helper.R\#L296-L298}{Lines 292-294} \textbf{\emph{Image Validation \& Conditional Cropping:}} Evaluates the maximum value of this matrix to check whether the image is entirely blank or empty. If valid content exists (the maximum pixel value is greater than zero), it applies \href{https://docs.ropensci.org/magick/reference/editing.html}{magick::image\_trim} to automatically crop out uniform background borders or whitespace, centering the content around the core visual features.
\item
  \href{https://github.com/AzKurban-edX-DS/edx.capstone.choose-your-own/blob/main/r/support-functions/data-helper.R\#L300}{(Line 296}) \textbf{\emph{Data Extraction:}} Finally, it extracts and returns the underlying raw pixel buffer data using the \href{https://docs.ropensci.org/magick/reference/editing.html\#details}{magick::image\_data} helper function.
\end{enumerate}
